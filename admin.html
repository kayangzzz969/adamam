Setiap kali Anda menekan tombol simpan film, event, atau profil, panel admin akan langsung menulis ke LocalStorage browser dan membuat commit baru di repositori GitHub Anda (file assets/js/data.js). Layanan hosting (Vercel/Netlify) yang terhubung ke GitHub akan otomatis men-deploy versi terbaru!

▲ Opsi 1: Vercel Cloud Storage (KV & Blob)
Mendeteksi Vercel...

Website ini sudah dilengkapi fungsi serverless di api/data.js dan konfigurasi vercel.json. Begitu dideploy ke Vercel dan dihubungkan ke Vercel KV (Redis) atau Vercel Blob, data yang Anda ubah di Admin langsung tersimpan otomatis ke cloud storage Vercel!

Cara Aktifkan Vercel KV (2 Klik):
1. Di Vercel Dashboard project Anda, klik tab Storage.
2. Klik Create Database → pilih KV (atau Blob) → klik Connect to Project. Selesai!
Opsi 2: Netlify Blobs Cloud Storage
Mendeteksi Netlify...

Sudah dipasangi serverless function di netlify/functions/data.js dan konfigurasi netlify.toml. Begitu diunggah ke Netlify, Netlify Blobs akan langsung aktif otomatis untuk menyimpan perubahan data secara global!

Opsi 3: Cloud REST API Mandiri (JSONBin.io)

Bisa digunakan di mana saja (GitHub Pages, Netlify Drop, Vercel). Cukup buat Bin gratis di jsonbin.io, lalu masukkan Bin ID & Master Key di bawah ini:

Panduan Deploy Website ke Vercel atau Netlify:

Deploy ke Vercel: Hubungkan repositori GitHub Anda ke vercel.com/new, lalu buat KV Database di menu Storage. Perubahan di admin langsung tersimpan di Vercel KV!

Deploy ke Netlify: Cukup drag-and-drop folder ini ke app.netlify.com/drop atau hubungkan via Git. Netlify Blobs akan aktif otomatis.

Simpan Permanen ke File (Ekspor data.js)
Data yang Anda ubah di Admin sudah otomatis tersimpan di browser (localStorage) dan langsung tampil di film.html & event.html. Jika ingin menyimpan perubahan ke file fisik agar bisa diupload ke hosting atau komputer lain, unduh file data.js baru di sini.
