Penyimpanan Cloud & Netlify

Hubungkan website ke cloud agar setiap film, event, dan bio yang Anda edit tersimpan di internet dan langsung tampil ke semua pengunjung!

Opsi 1: Netlify Blobs Cloud Storage (Bawaan)
Mendeteksi Netlify...

Website ini sudah dipasangi serverless function di netlify/functions/data.js dan konfigurasi netlify.toml. Begitu Anda mengunggah folder ini ke Netlify, Netlify Blobs akan langsung aktif otomatis untuk menyimpan perubahan data secara global!

Opsi 2: Cloud REST API Mandiri (JSONBin.io)

Sangat berguna jika Anda mengunggah via Netlify Drop (drag-and-drop file gratis), GitHub Pages, atau Vercel. Cukup buat Bin gratis di jsonbin.io, lalu masukkan Bin ID & Master Key di bawah ini:

Cara Deploy Website Ini ke Netlify (Gratis):
  1. Buka website app.netlify.com/drop di browser Anda.
  2. Tarik (drag & drop) seluruh folder adamxavier-fanbase ini ke kotak unggahan Netlify.
  3. Netlify akan memberikan URL online gratis (misal: adamunited.netlify.app).
  4. Buka namasitus.netlify.app/admin.html untuk mengelola film, event, dan bio langsung secara online!
Simpan Permanen ke File (Ekspor data.js)
Data yang Anda ubah di Admin sudah otomatis tersimpan di browser (localStorage) dan langsung tampil di film.html & event.html. Jika ingin menyimpan perubahan ke file fisik agar bisa diupload ke hosting atau komputer lain, unduh file data.js baru di sini.
